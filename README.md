# 伪夜视 Fake Night Vision

Minecraft 1.20.1 Forge 纯客户端模组：无需夜视药水，强制客户端以夜视亮度渲染世界；可选消除监守者的黑暗效果。

伪夜视机制移植自 Tweakermore 的 fakeNightVision（https://github.com/Fallen-Breath/tweakermore）。

## 功能

- **伪夜视**：将渲染管线的夜视强度强制为满值，无药水到期时的闪烁
- **三态模式**：按键循环切换 关闭 → 常开 → 自动
- **自动模式**：定期采样玩家所在位置的等效亮度（方块光与天空光取较大值，天空光考虑昼夜与天气衰减），暗则自动开启、亮则自动关闭，带回滞避免在阈值附近反复切换
- **平滑渐变**：开关切换时画面亮度在约 0.5 秒内线性过渡，无突变
- **黑暗消除**：消除监守者与幽匿尖啸体施加的黑暗效果（雾色压暗与脉冲），仅影响画面，心跳音效与粒子不受影响

## 按键

默认 **小键盘 9** 循环切换模式（关闭 → 常开 → 自动），可在"选项 → 控制 → 键位设置"中修改，切换时状态栏提示当前模式与判定亮度。

## 配置

配置文件位于 `config/fakenightvision-client.toml`：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `mode` | `OFF` | 伪夜视模式：`OFF` 关闭 / `ON` 常开 / `AUTO` 自动 |
| `autoLightThreshold` | `6` | AUTO 模式亮度阈值（0~15）：等效亮度 ≤ 阈值开启，≥ 阈值+2 关闭 |
| `removeDarkness` | `true` | 消除监守者/幽匿尖啸体的黑暗效果 |

## 安装

- Minecraft 1.20.1 + Forge 47.x（客户端）
- 将 jar 放入 `mods` 文件夹

仅客户端模组，多人游戏中服务端无需安装。

## 构建

需要 JDK 17：

```bash
./gradlew build
```

产物位于 `build/libs/`。
